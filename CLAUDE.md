# Zasady współpracy z właścicielem

- Właściciel pisze po polsku i nie jest programistą. Odpowiadaj po polsku, prostym językiem i krótko.
- Jeśli czegoś od właściciela potrzebujesz (decyzja, kliknięcie, konfiguracja), zakończ wiadomość sekcją
  **„Akcje dla Ciebie”** z ponumerowaną listą konkretnych rzeczy do zrobienia. Gdy nic nie jest potrzebne,
  pomiń tę sekcję.
- Opis projektu, struktury kodu i pipeline danych jest w README.md.
- Push do `main` od razu publikuje grę: przed pushem `npm test` i `npm run build`.
